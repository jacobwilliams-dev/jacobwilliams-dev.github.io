# Elevator pitch – Script #2


## Script

Hi, my name is Jacob Williams. I'm a full stack developer and a recent CodeBoxx Academy graduate, and I love building web and mobile apps that are fast and easy to use.

On the front end, I use React and React Native. On the back end, I use Node.js and Java Spring Boot. I've built REST APIs, secure logins and mobile apps.

I have a sharp eye for detail, and I don't let a hard bug go until I find what's really causing it.

I adjust quickly to new tools and new teams. At CodeBoxx, I moved between four different tech stacks in four months.

I want to build products that make everyday life easier for people.

I'm excited to join a strong team as a junior developer. You can see my work at jacobwilliams-dev.github.io, or find me on LinkedIn.



## What changed from Script #1

1. The opener is tighter. It drops the filler word "actually" and adds that I'm a CodeBoxx Academy graduate.
2. The tech list is split into front end and back end, so it's easier to say and easier to remember.
3. Three soft skills became two, and each one is more concrete.
4. "Projects that make people's lives easier" now says who the products are for.
5. The close names the role I want and tells recruiters where to find me: my portfolio and LinkedIn.
